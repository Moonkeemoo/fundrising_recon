# SETUP-KEYS — як дістати ключі доступу

Гайд для отримання креденшалів, які потрібні для **реального** збору даних.
Код працює без них (graceful-skip із логом), але кожен ключ «оживляє» своє джерело.

Усі ключі кладемо у файл **`.env`** в корені репозиторію (він у `.gitignore` —
**ніколи не комітимо**). Зразок — у `.env.example`.

> Порада: роби по одному. Найшвидші — YouTube і Telegram (5-10 хв кожен).
> Найдовший/найвибагливіший — Meta Ad Library (може знадобитись підтвердження особи).

---

## 1. YouTube Data API v3 (найпростіше, ~5 хв)

Дає: телетони, відеозвернення, перегляди/лайки (сигнал віральності).

1. Зайди на **https://console.cloud.google.com/** (потрібен Google-акаунт).
2. Угорі — **створи проєкт** (Select a project → New Project), назва будь-яка (напр. `fundrec`).
3. У пошуку зверху введи **«YouTube Data API v3»** → відкрий → натисни **Enable**.
4. Ліворуч **APIs & Services → Credentials → Create Credentials → API key**.
5. Скопіюй ключ. (Опційно: Restrict key → API restrictions → YouTube Data API v3.)
6. У `.env`:
   ```
   YOUTUBE_API_KEY=AIza....твій_ключ
   ```

Ліміт за замовчуванням — 10 000 одиниць/день (вистачає; збір резюмований).

---

## 2. Telegram api_id / api_hash (~10 хв, є разовий логін)

Дає: публічні Telegram-канали зборів (пости, реакції, перегляди).

1. Зайди на **https://my.telegram.org/** → увійди за номером телефону (прийде код у Telegram).
2. Відкрий **API development tools**.
3. Заповни форму нового застосунку:
   - **App title:** `fundrec`
   - **Short name:** `fundrec`
   - платформа/URL — будь-що (напр. `Desktop`, URL лиши порожнім або `https://example.com`).
4. Після створення побачиш **`api_id`** (число) і **`api_hash`** (рядок). Скопіюй обидва.
5. У `.env`:
   ```
   TELEGRAM_API_ID=1234567
   TELEGRAM_API_HASH=твій_hash
   ```
6. **Разовий логін:** під час першого живого прогону Telethon попросить номер телефону
   й код підтвердження (одноразово) — створиться файл сесії `data/.telegram.session`
   (він у `.gitignore`). Далі — автоматично.

> Збираємо лише **публічні** канали. Приватні чати/контакти — ні (PII-лінія).

---

## 3. Meta Ad Library API (FB / Instagram / Threads реклама) — найцінніше, але найвибагливіше

Дає: **реальні рекламні креативи** (текст, медіа, формат), дати, для частини
оголошень — діапазони витрат/охоплення; сторінку-рекламодавця.

> ⚠️ Нюанс: повний програмний доступ до Ad Library API історично потребує
> **підтвердження особи** і часто обмежений оголошеннями «про соц. питання,
> вибори чи політику». Комерційні/благодійні оголошення можуть бути доступні
> частково. Якщо API-доступ застрягне — у нас є **запасний шлях**: публічний
> веб-інтерфейс Ad Library + парсер сторінок (нижче).

### Шлях A — офіційний API (пробуємо першим)
1. **https://developers.facebook.com/** → увійди → **My Apps → Create App**.
   Тип застосунку — «Other» / «Business» (підійде базовий).
2. У застосунку додай продукт або просто отримай токен через **Graph API Explorer**:
   **https://developers.facebook.com/tools/explorer/** → обери свій App → **Generate Access Token**.
3. Для Ad Library потрібне **підтвердження особи й місцезнаходження**:
   **https://www.facebook.com/ID** (Identity Confirmation) — пройди, якщо просить
   (паспорт/ID + країна). Це найдовший крок (від годин до 1-2 днів на модерацію).
4. Робочий ендпоінт: `GET https://graph.facebook.com/v21.0/ads_archive`
   з параметрами `ad_reached_countries=["UA"]`, `search_terms="..."`, `ad_type=...`,
   `access_token=...`. (Точні поля з'ясуємо на живому прогоні — recon у фазі F2.)
5. У `.env`:
   ```
   META_ADS_TOKEN=EAAB....твій_токен
   ```

### Шлях B — публічний веб (fallback, без верифікації)
- Ручний перегляд: **https://www.facebook.com/ads/library/** (фільтр країна = Ukraine,
  пошук по ключових словах/сторінці). Якщо API не дадуть — підключимо парсер цих
  публічних сторінок (повільніше, але без токена).

> Якщо застрягнеш на Meta — не блокуйся: дай YouTube + Telegram, а Meta підтягнемо
> через Шлях B або пізніше через API.

## Куди класти і як перевірити

1. Скопіюй `.env.example` → `.env` (у корені репо).
2. Встав ключі, які вже маєш (решту лиши порожніми — джерело просто пропуститься).
3. Перевірити, що бачаться:
   ```
   python -m fundrec.config --check-keys     # покаже, які ключі задані (значень не друкує)
   ```
   *(команду додам у фазі F2)*

**Безпека:** `.env` ніколи не потрапляє в git. Не надсилай ключі в чат/скріншоти —
просто поклади їх у `.env` локально.
